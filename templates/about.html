ℹ About Project

Secure Cloud Document Management System

📌 Project Overview

This project is a secure cloud-based document management system that allows users to upload, download, view and delete documents stored securely in AWS S3.

It provides authentication, session management, password security, and cloud integration using modern web technologies.

🛠 Technologies Used

Flask SQLite AWS S3 Bootstrap 5 Python HTML/CSS

🔒 Security Features

  • Password Hashing
  • Session Authentication
  • AWS IAM Integration
  • Secure Cloud Storage
  • Protected File Access
  • Pre-signed Download URLs
